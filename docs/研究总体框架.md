毕设项目交接说明
1. 项目概况

题目（暂定）：基于残差强化学习与柔顺控制的机器人精密插接方法研究
层次：本科毕业设计
学科归属：机器人学习 / 强化学习应用 / 智能控制交叉方向，不是纯机器学习理论方向。
核心工作定位：不是提出新 RL 算法，而是在标准化仿真基准上完成残差 PPO 与固定柔顺基线的受控实现与对比评估，回答“残差补偿在什么位姿误差范围内真正有效、训练信号结构如何影响残差行为”这类边界性问题。
2. 研究问题与目标

精密插接中，初始位姿误差和接触干扰会导致位置控制失败。项目采用残差强化学习：保留一个基础控制器负责插接的基本推进与柔顺行为，让 PPO 只学习有界的局部运动补偿（初期为垂直于插入方向的二维横向补偿），以改善接触稳定性和插入成功率。

本科毕设的合理贡献边界：

    在 Isaac Lab 的 FORGE PegInsert 环境中复现基础插接与固定柔顺基线；

    接入 PPO 残差策略，完成训练闭环；

    做受控对比：位置控制 / 固定柔顺 / 柔顺+残差；

    给出残差补偿在不同初始位姿噪声下的有效边界，或奖励信号结构对残差行为的影响；

    不要求统计上显著优于现有方法，但要求对照干净、失效讲清楚。

需要警惕的论证风险：FORGE 在仿真中成功率本身接近饱和（官方策略仿真可达 97%–99%，但真实部署退化严重）。因此论文核心结论不能停留在“我的残差策略仿真成功率更高”，而应转向“残差补偿的有效边界”“训练信号与残差接触行为的关系”等可解释问题。
3. 技术路线

    固定版本搭建 Isaac Lab + Isaac Sim 环境；

    跑通空场景、Franka 差分 IK 基础运控；

    复现 Isaac-Forge-PegInsert-Direct-v0 零动作环境；

    实现基础轴向推进 + 固定参数柔顺控制基线；

    接入 PPO 残差策略：观测含末端相对位姿、速度、接触力、插入深度、上一时刻残差；动作为二维横向补偿；基础控制器负责轴向推进；

    训练与对比实验：不同初始位姿偏差（如 σ=2/3/5 mm）下比较成功率、峰值接触力、插入时间；

    可选消融：密集多项目标奖励 vs 稀疏成功+统一力约束项；或残差维度/柔顺参数敏感性。

暂不接入 cuRobo。cuRobo 仅作为后续可选组件，用于从初始位姿规划到预插入位姿，不替代接触阶段的柔顺控制与残差学习。
