## 二、代码修改

### 2.1 区间事件时钟按回合重置

`EventManager._interval_term_time_left` 每回合重置为区间中点（FORGE 死区区间为 (2, 2)，即精确 2.0 s）；并在 `env.reset()` 之后再次按回合号播种，使本回合运行期的死区抽样与观测噪声只依赖 `seed*1000+ep`。

后果：同一 `ep_seed` 的回合，其事件时刻与抽样序列与上一回合长度无关。

### 2.2 终态判据改在环境内部捕获

在 `DirectRLEnv.step` 的内部顺序（`_get_dones` → `_get_rewards` → `_reset_idx`）中，挂接 `_get_rewards`，在**复位之前**捕获：

- 本步物理计算后的几何成功；
- 平滑接触力三轴、当回合阈值；
- 回合内步号、terminated / truncated 标志。

终止分支改为：

| 情形 | 标记 |
|---|---|
| 正常到时且终态成功 | `SUCCESS` / `success_at_env_done` |
| 正常到时且未成功 | `ENV_DONE` / `env_done` |
| 非 done 步出现阈值变化（静默复位） | `INVALID` / `boundary_violation` |

即：**正常到时不再被误判为无效**；末步成功不再漏判。

### 2.3 复位指纹补字段

新增 `interval_clocks_s`（开局事件倒计时），保留销/孔/末端真值、阈值、增益、EMA、死区、`episode_length_buf`。CSV 逐行记录 `done`、`reset_fp`，每回合 `reset_events`（阈值重抽步号，延长时限后应为空）。

### 2.4 比较工具加固（对应复审的 7 个反例）

| 复审反例 | 处理 |
|---|---|
| 两侧同时去掉完整指纹 → 用 1 mm 容差放行 | 缺指纹即拒绝；仅 `--allow_loose` 可退化为描述性比对，并明确标注未认证 |
| 两侧同删一个回合 → 仍给通过结论 | 与配置声明的回合数/编号比对 |
| 删除末行成功步 → 残段计为 TIMEOUT | 末行无终止标签即判 `UNTERMINATED` 并拒绝 |
| 回合中间插 `done=1` → 仍称窗口连续 | 中途 `done=1` 判边界异常并拒绝 |
| `success_at_env_done` 被归为 TIMEOUT | 结局映射改为计成功 |
| 改 `control_dt_s` → 放行 | 时间口径（`episode_length_s`/`control_dt_s`/`max_episode_length_steps`）不一致即拒绝 |
| 同一份数据与自身比较 → 输出 p≈1.0 | 自比较直接拒绝 |
| 配对成功标签全同 → 仍输出检验 | 改为"不一致对为 0，不做显著性检验" |
| 分叉定位 | 新增逐回合"首个分叉步"报告（phase/位姿/目标/力/z_cmd/实际动作逐列比对） |

2. **`--keep_official_limit` 下的 done 分支**：新逻辑已覆盖，但尚未实际触发验证（需要一次真实的正常到时）。
