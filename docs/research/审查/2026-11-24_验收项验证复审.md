### 终态时间点

08 先在动作前读 `success_pre`。Isaac Lab 随后执行动作、推进物理、计算 done 和奖励、复位结束的环境，最后返回观测。真正的终态位于**最后一个动作之后、自动复位之前**。如果最后一步首次插入成功，`success_pre` 仍为假。返回后的阈值一旦改变，08 就写入 `boundary_violation` 并跳过 done 分支。两个独立探针的 EP01 都在步号 148 正常到时。环境内采到的最后一步几何成功均为假，阈值均为 **6.1120 N**；两份 CSV 的末行都写了 `done=1`、`boundary_violation` 和下一场景的 **9.9284 N**，三轴力也与复位前采样不同。这证实了普通到时的误判。最后一步首次成功仍是代码推演的漏判路径。原报告的三份 CSV 没有触发自动复位，原有计数保留。[08 终止逻辑](../../../demos/08_staged_baseline.py#L326) · [Isaac Lab v2.3.0 官方步进实现](https://github.com/isaac-sim/IsaacLab/blob/v2.3.0/source/isaaclab/isaaclab/envs/direct_rl_env.py) · [FORGE 在奖励中已读取的成功与力](../../../IsaacLab/source/isaaclab_tasks/isaaclab_tasks/direct/forge/forge_env.py#L227)

修复时在环境内把本步物理计算后的几何成功、平滑力、旧阈值、终止标志和步号按环境复制出来，由评估器在复位后消费。同一步几何成功与超力可同时为真。官方时限正常到点应结束该次尝试；缺失终态或跨入下一场景继续计数需标为无效。验收至少区分普通到时、最后一步首次成功、成功与超力同一步。后两种稀有边界可用给定前后状态的确定性测试覆盖，并把仿真实际触发的案例另列。

## 比较工具的实测反例

直接执行当前比较工具。原始 3 对 5 返回 1，能报出回合数和编号差异。其余反例从原 3 回合 CSV 和 JSON 生成临时副本，每次只作表内所述改动。修改脚本 SHA、改变一个指纹值、制造回合内阈值跳变、修改两项 CLI、移除整份 JSON 都得到退出码 1。[比较工具](../../../tools/compare_runs.py)

| 输入或改动 | 实际退出码 | 工具输出或误判 |
|---|---:|---|
| 两侧都有 JSON，同时去掉完整指纹 | 0 | 用首步动作后的 xyz、逐轴 1 mm 容差放行严格配对 |
| 两侧 CSV 同删 EP02，配置仍声明 3 回合 | 0 | 用剩余 2 回合给出通过结论 |
| 仅删一侧 EP02 的最后一个成功步 | 0 | 把不足 600 步且无终止标签的残段计为 TIMEOUT |
| 仅置一侧回合中间一行 `done=1`，阈值保持不变 | 0 | 宣称窗口连续，继续用后续行统计 |
| 一侧末行改成脚本定义的 `success_at_env_done` 并写 `done=1` | 0 | 把成功归为 TIMEOUT，产生虚假的成功差异 |
| 仅改变 JSON 内 `control_dt_s` | 0 | 实际时间口径不同仍放行 |
| 同一份 3 回合数据与自身比较 | 0 | 输出非配对 Fisher 的 p≈1.000，并称可用于单因素对照 |

原始 3 对 5 在拒绝前也打印了 Fisher p≈1.000，两个样本的前三个场景完全重叠。这个检验不满足样本独立的前提。工具要分清同配置重放和指定因素的配对效应。严格模式先核对配置中声明的回合集、指定因素、时间口径、必要指纹、按步连续性和完整终态，再输出推断统计。旧数据缺必要字段时保留描述输出。配对成功与否完全一致时直接报告零个不一致对即可。[回合分类](../../../tools/compare_runs.py#L38) · [配对检查](../../../tools/compare_runs.py#L158) · [统计分支](../../../tools/compare_runs.py#L235)

前期审查漏掉 gate 对照的问题，具体失误是把“代码确实执行了重播种”当作“物理状态和随机事件历史都复位了”，并在看到成功率前没有先比较 gate 生效前的 A 阶段。上一轮已提出长短历史测试，这次还须验收执行者是否真的改变了上一回合步数。今后的配对审查先看干预前的共同轨迹、随机事件时间和刻意构造的失败输入，再看成功率和显著性。[审查方法](README.md)

## 下一轮的优先顺序

1. **先修评估器，可以同时移植 A+B。** 以本轮的短历史、长历史为回归用例。在专用配对评估模式下让死区事件相对每回合重新计时且随机抽样可重放，或提供事先生成的每场景扰动表。记录开局计时、前两次触发步和值，加上统一控制输入下的 A 段轨迹。修完先小样本比较，预先说明数值容差；若仍有首个差异，沿该步追查。注明改变过的评估协议，协议变更后的各方法在同一协议下重新评估。
2. **保留 3 mm，补齐默认难度的比较。** 21/30 是 seed 家族 42、外层 600 步（40 秒）预算下的开发结果。可现在运行 43、44 各 30 回合作为单方法验证；正式方法间配对使用已验证的共同场景。将实验一位置基线、3 mm A+B、零残差及训练后的残差策略放进同一评估器，统一观察量、首次终止规则和预算。按种子分别给出分子、分母；评估场景与 PPO 调参、选 checkpoint 的场景分开。
3. **默认难度 PPO 的前置检查是零残差等价。** 当前残差环境仍调用带随机化的螺旋基座，08 使用 A 对中和 B 条件缓降。先移植冻结控制律，核对逐环境 reset、复位时的 EMA 初值、目标动作和平滑后实际动作，以及首次成功、超力与超时；在同一输入下定位首个分歧。通过后开始默认难度训练。残差控制论文以已知反馈控制量与学习修正量叠加为出发点；这里用零残差验证项目自身的实现。[现有残差环境](../../../forge_ext/residual_env.py#L154) · [现有基座](../../../forge_ext/base_policy.py) · [Johannink 等，Residual Reinforcement Learning for Robot Control](https://arxiv.org/abs/1812.03201)
4. **接受难度扩展，列为泛化实验。** 先保留每轴 ±20 mm 的设置，再单独改变手部初始 x、y 采样半宽到 ±25、±30 mm。记录 reset 后销孔真实径向偏差，避免把采样半宽直接写成实际径向误差。各策略复用预定场景，单列默认难度和扩展难度。开题要求的误差鲁棒性由这组实验回答。
5. **接受力作为第二目标。** 分母统一为全部有效尝试，同时报告几何成功率、全程已采样平滑力未超当回合阈值的成功率、任一采样超限率，以及全尝试峰值力和峰值/阈值分布。成功子集峰值作补充。此前 8/21 达到阈值的 70% 可用于描述，尚不足以诊断冲撞；70% 属项目选取的描述线。FORGE 原论文将允许力阈值与动力学随机化纳入策略学习，本项目的控制步采样指标与之有明确关联。[前一轮复核](2026-11-24_本轮结果与后期方向复核.md) · [Noseworthy 等，FORGE](https://arxiv.org/abs/2408.04587)

如果相同场景重放在限定工期内仍达不到预定容差，可以改用预先划分、按同一分布独立抽样的评估组，报告各方法的不确定性并注明设计。现有共用种子、共享部分场景的记录保留作描述。每轮同时列出计划尝试数、有效数和无效原因，避免数据损坏改变指标分母。
