# 毕设实验审查方法

先写下本轮要支持的论文结论和它将改变的决策。对每项关键结论，找一个能推翻它的观测，用原始轨迹和实际执行代码去查，再决定是否需要新实验。

| 曾经漏掉的问题 | 后续审查动作 |
|---|---|
| 600 步的脚本窗口内环境自动复位 | 从指定初态追到首次成功、中止或超时，检查物理时限、done 和终态采样顺序。全表扫描回合中应保持恒定的量。旧日志里 step 148 力阈值跳变就是反例。 |
| 同 seed 被当作同场景 | 核对动作前的真实位姿和随机化参数，记录容差。若只改 B 段 gate，先比较 A 段动作、观测和切换时刻。让上一回合分别提前和延后结束，检查下一指定场景是否仍可重放。 |
| 成功深度和力中止被误读 | 追到判据两端的参考物体、原点、单位和不等式，代入边界姿态。分别记录几何成功与全程采样超限，允许同一步同时发生。 |
| 把下降暂停统一归因为横向漂移 | 用控制器实际读取的上一帧重建决策，分解仅横向门槛、仅轴力预警、两者同时和其他原因。未进入阶段的回合单列，说明按步还是按回合加权。 |
| 为了给学习留下提升空间而调难任务 | 先问这项实验能区分哪些假设。使用冻结的基座、统一评估器和留出场景验证学习增益。难度扫描留给明确的泛化问题，文献和开源实现用来校准任务条件及指标。 |

每轮给出可引用结论及范围、最强反例或替代解释、对下一步的裁定。若一个问题能由旧日志解决，直接复算。若证据缺失，说明哪项补测的哪种结果会改变决策。新发现影响历史结论时，标出对应轮次并勘误。

当前采用 3 mm A+B 配置。21/30 是种子家族 42、40 秒尝试预算的观测值。下一轮优先核查留出场景、统一时限和零残差等价性。从相同场景比较独立控制器和零残差环境的目标、平滑后动作、状态切换和终局事件，定位首个差异。正式对照同时报告几何成功、全程采样力合规的成功和全体尝试超限。

核验工具时，保留一份已知正常的输入，再分别制造指纹缺失、两侧同缺一回合、末步丢失、终态标签改变等反例。分别记录退出码、统计输出和标签是否正确。核验因果结论时，明确干预哪一回合的哪一项，以及下一回合哪个观测会推翻结论。
